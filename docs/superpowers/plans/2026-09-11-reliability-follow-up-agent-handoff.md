- [ ] 校验与降级继续共用同一套内容支持判定。即使来源未确认，也必须先确认原文实际表达了该内容。
- [ ] 补测试：未确认证据明确包含该说法，可以降为 `statement`；已确认证据支持完整断言，保持 `fact`。

- [ ] 先找开销最大的环节，再选择一项最小优化：减少无必要的 finish 调用、减少重复背景板输出，或减少适配层会话开销。每次只改一项，以便归因。
- [ ] 不预设必须换模型，不通过再次拉长 Nginx 超时宣称性能改善。保留已有证据与安全要求。
